# 安全边界

本 CLI 的定位是“受控的数据入口”，不是权限后门。

- 后台现有账号、角色、数据范围仍是最终权限依据。CLI 不直接连接数据库，也不伪造管理员权限。
- 默认只暴露经过白名单登记的查询接口，不提供新增、编辑、删除、审批等写操作。
- 工资资源除后台权限外，还要求调用方显式传入 `--include-sensitive`。
- 手机号、证件号、银行卡、邮箱和地址默认替换为 `[REDACTED]`；只有显式使用 `--include-pii` 才输出原值。
- token 优先从 `MOEDU_TOKEN` 环境变量读取，并兼容 `MOEDU_ADMIN_TOKEN`；交互登录后保存到本机配置文件，权限为 `0600`。
- CLI 登录默认使用独立的 `type=4` 会话，避免 PC/H5 登录轮换掉智能体 token；服务端仍按现有账号、角色和 7 天滑动过期规则校验。
- 正式域名只允许通过 HTTPS 访问；历史保存的 `http://crm.moedu.com` 在客户端解析时自动升级为 HTTPS。
- `auth browser-login` 只在 `127.0.0.1` 临时监听，使用一次性随机状态值并限制表单大小；页面禁止缓存、外部资源、跨站表单和嵌套。密码不写入配置或日志，成功后仅保存 token。
- 本地审计日志只记录智能体标识、资源、请求 ID、耗时和行数，不记录 token、筛选值或返回数据。

`--include-sensitive` 和 `--include-pii` 是防误用开关，不是服务端安全机制。真正的隔离必须由 CRM 后台角色和数据范围配置保证。

默认连接正式 HTTPS 地址 `https://crm.moedu.com`。生产使用应优先采用个人账号或最小权限专用账号；管理员账号的查询结果不能作为普通用户隔离已验证的证据。
